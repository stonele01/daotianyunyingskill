按你的任务使用

  1. 找参考
  2. 拆解视频

  6. 复盘归档

选一个场景，复制指令开始

把【括号内容】换成你的实际信息，再把文件或链接一起交给 Agent。

01

找同款参考视频

准备：产品名称或图片、目标平台

使用稻田运营技能，帮我找【产品名称或图片】在快手的同款高表现视频。核对是否同款，给出原链接、可见数据和推荐理由。没有足够指标的请标为参考候选。

交付：同款候选清单、来源链接、匹配证据和筛选理由。

02

拆解视频画面和声音

准备：视频文件或可获取的链接

使用稻田运营技能，拆解【视频文件或链接】。分析画面、口播、字幕、音乐音效及时间关系，整理开头、卖点展示、节奏和结尾。重要判断附时间点与证据，分清观察和推测。

交付：声画时间线、关键画面证据、内容结构和可借鉴点。

03

分析抖音对标账号

准备：准确的抖音号或主页链接

使用稻田运营技能，分析【抖音号或主页链接】。核对账号身份，整理作品表现、评论需求、代表视频结构和口播金句，生成带截图证据的报告并导出 ZIP。缺失内容请明确标注。

交付：账号洞察、评论原文依据、作品拆解和可分享的报告。

04

写三条原创脚本

准备：产品事实、受众、时长和拍摄条件

使用稻田运营技能，为【产品】写 3 条有实质差异的原创脚本和分镜。参考【视频或分析】，已确认卖点是【卖点】，面向【人群】，时长约【秒数】，拍摄条件是【人员、场地、素材】。不要编造产品事实。

交付：三条差异脚本、分镜、字幕或口播及拍摄交接材料。

05

审核和修改脚本

准备：现有脚本、品牌要求与产品依据

使用稻田运营技能，审核【脚本附件或正文】。检查内容结构、产品事实、品牌要求和潜在风险。品牌要求是【要求】。标出问题、原因和可直接替换的修改建议。

交付：问题清单、修改稿和需要人工确认的事实。

06

分析报表和运营复盘

准备：有权提供的 Excel 或 CSV 报表

使用稻田运营技能，分析这份【快手或抖音】报表。先检查指标含义、日期范围、重复和缺失，再比较素材表现。附计算依据，标出数据不足，并提出下一轮选题和脚本测试建议。

交付：数据质量说明、汇总和图表、分析结论及下一轮测试建议。

07

整理可复用案例

准备：素材、旧稿或历史报告

使用稻田运营技能，把【素材、旧稿或报告】整理成可复用案例，保留来源、适用场景、证据、可借鉴方法和限制，并建立索引。

交付：案例卡、素材目录和检索索引。

也可以一句话做完整流程

使用稻田运营技能，为【产品】在快手找同款参考视频，挑出值得借鉴的作品做声画拆解，再结合【卖点、受众和拍摄条件】写 3 条原创脚本与分镜，完成审核并交付可拍摄版本。缺少事实时先列出，不要编造。

拿到结果，先检查这三件事

  1. 对象和范围：账号、产品和视频是否正确，采集时间与样本量是否清楚。
  2. 证据：重要判断能否对应原链接、评论原文、视频时间点或计算依据。
  3. 可执行性：脚本是否符合产品事实、品牌要求和实际拍摄条件。

分享 HTML 报告时发送完整 ZIP，对方解压后打开入口页，避免图片丢失。

使用时记住

  • 支持 Skill 的 Agent 才能安装使用；搜索、声画理解和数据计算取决于实际可用工具。
  • 抖音账号报告和快手任务分别处理。本技能不默认登录公司后台，也不包含千川自动盯盘。
  • “高表现”是样本内比较，评论意向不等于真实成交；AI 的解释需要结合业务验证。
  • 采集、转写和模型可能产生费用。已有材料尽量复用，产品承诺和最终发布由员工确认。

# 读取重点作品的评论正文

只有任务需要分析受众疑问、选题或内容反馈时使用。沿用作品 candidate_id，用宿主允许的浏览器/已配置 web-access 打开原作品评论区，或调用用户已授权且本次可用的数据源。

保存实际读取到的评论文本、作品 ID、评论 ID（有则保留）、观测时间、可见点赞、一级/回复层级及来源位置。不要为选题额外采集个人资料；对用户交付以问题文本和必要出处为主。

记录排序方式、页面展示总数、实际条数、去重条数、覆盖层级及停止原因。展示总数和已得一级评论不同，不能推断平台固定隐藏比例；没有读取二级回复就不能断言无人回答。读取失败时如实记失败，不把已有评论数量当正文。

归纳需求、购买顾虑、使用方法、替代品比较和效果反馈。每个主题绑定代表原句/来源及相应样本数。关键词分类只作初筛，人工或模型逐条核对影响结论的样本；一个评论可属多个主题，说明分母与重叠。不得用病症提问推断具体评论者的诊断。

输出 `主题｜样本中的证据｜相关作品已解释什么｜仍需核查的缺口｜候选选题｜商品事实/专业审核依赖`。未读全账号时，只能说当前样本未覆盖；收藏、提问及品牌提及不能证明购买、专业信任或成交。

若用户要求原创稿，选用合适问题交给 production.md。不得虚构用户亲测、复制未经证实的功效反馈作为广告证明或自动回复/发布评论。
